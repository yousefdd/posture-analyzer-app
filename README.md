# محلل الوضعيات · Posture Analyzer

محلل الأداء الرياضي للجوال: يحلل بالكاميرا الوقفة الرياضية (المسافة بين القدمين)، والسكوات، والبوش أب، ويعطي تقريراً بدرجة من 100.

- تحليل مباشر بالكاميرا الأمامية أو الخلفية، مع عدّ تنازلي وإيقاف مؤقت وتصفير ومعايرة.
- تحليل فيديو من المعرض.
- تسجيل فيديو الجلسة في المعرض.
- سجل الجلسات، ومشاركة التقرير.
- الصور تُحلَّل داخل الهاتف فقط (Google ML Kit Pose Detection).

Built with Flutter. `flutter test` runs the analysis tests; CI builds the APK and publishes it as the latest release on every push to `main`.
